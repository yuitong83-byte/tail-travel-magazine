日期与景点仅作为旅游参考，公开版不展示完整个人医疗/出行安排。

noindex与robots仅减少收录，不提供访问控制。公开GitHub仓库的全部文件和历史都能被查看。
同网址更新通常保留本机记录；换域名、清理Safari、私密模式或系统清理可能丢失，需导出备份。
